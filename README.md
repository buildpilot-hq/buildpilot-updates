# BuildPilot Partner Dashboard

Updated November 22, 2026

## BuildPilot overview

BuildPilot is being developed as a workspace for residential contractors. The goal is to help office and field teams manage projects, schedules, documents, inspections, and follow-up work in one place. Each contractor will have a separate company workspace.

## Current development status

BuildPilot is in development. The team has tested navigation, sign-in, and access controls in local prototypes using sample data. Customers do not yet have access to a production service. Core construction workflows remain planned.

## Latest completed milestone

**Company and project access foundation, Phase 1.4C Part 1** was accepted on November 21, 2026.

In a local prototype, users from one contractor were blocked from opening another contractor's sample project records. The team also verified that a user's role and assignments control the work they can access. This is a step toward letting contractors keep each company's information private and share project work with the people responsible for it.

## What's next

The next proposed milestone is to verify that BuildPilot clears project information from an open screen when someone's access changes. Implementation awaits owner approval. Later work will cover controlled onboarding and the checks needed before a live pilot.

## High-level roadmap

1. **Prepare for a pilot.** Finish access checks, controlled account setup, and live pilot readiness review.
2. **Build contractor workflows.** Planned priorities include project coordination, scheduling, inspections, deficiency tracking, and documents for office and field teams.
3. **Expand collaboration.** Estimating and budgets, subcontractor coordination, client access, and warranty follow-up are planned areas for later milestones.

## Important decisions and outstanding considerations

- Company information stays separate. Access is based on each person's role and assigned work.
- Internal inspection records will be kept distinct from official municipal or regulatory approvals.
- Software security and browser reliability follow-ups remain open. Live pilot timing depends on readiness checks and separate owner approval.
